# 第 10 章：关键帧、回环与二维 SLAM

先修第08–09章与SE(2)。本章完成位姿图内核、关键帧和局部回环验证，重建观测点云/栅格并发布map→odom。
先用独立合成实验验证优化器，再运行真实扫描/IMU管线；两种实验的指标不混用。

重新构建并加载ROS环境，在仓库根目录运行：

```bash
ros2 run motion2d pose_graph_demo tmp/ch10_graph
/usr/bin/python3 scripts/plot_ch10_graph.py
```

节点位姿Ti在map坐标，测量Zij把j坐标变到i坐标；误差是`Zij^-1 Ti^-1 Tj`的平移与归一化角度，
不是SE(2)对数映射。位置/航向使用加性更新，公开雅可比在`estimation/pose_graph.cpp`。
固定第0帧的三个量，使用Eigen稀疏LDLT和回溯线搜索。报告迭代上限、不可连通、奇异、求解失败和线搜索失败，
不把任何一次下降伪装为收敛。仅对回环的白化残差范数施加Huber，默认阈值3。

合成图为4×3 m矩形，80条相对边、81个节点；每步位置sigma=.01 m，航向sigma=.002 rad加固定.003 rad偏差，
seed=1010。边残差标准差(.03,.03,.02)，最后可加一条回到原点的独立约束，尺度(.02,.02,.01)。
第一帧始终固定原点。图中的参考位置仅评估RMSE，约束由实验生成器给出；这一步尚无地点识别或传感器配准。

核心验证：雅可比中心差分、非零首帧坐标、已知闭环恢复、一维加权解析解、错误回环鲁棒影响与断开图。
练习ch10-1推导并实现边残差；理解固定首帧与鲁棒损失局限。代码公开接口采用Doxygen。


## 完整管线

```bash
ros2 launch motion2d_bringup ch10.launch.py rviz:=false
# 另一个终端加载相同环境后，从仓库根目录运行
/usr/bin/python3 scripts/check_ch10.py
ros2 run motion2d slam_demo tmp/ch10_slam
/usr/bin/python3 scripts/plot_ch10_slam.py
```

前端沿用第09章，后端只接 `/scan` 和精确同时间的 `/odometry/scan`；没有世界几何、真值或TF输入。
平移.3 m、转动.25 rad或经过2 s创建关键帧，保留原始距离读数和机体系体素点云。
默认排除最近20个关键帧，距离.8 m、航向差.6 rad以内最多检查三个旧候选。
每次回环之间至少隔5个新关键帧；总容量200，超过时报capacity_reached，未做长期地图管理。

候选必须通过双向点到线匹配、至少55%有效对应、.05 m残差、退化检查、最大.5 m/.25 rad校正，
以及往返.03 m/.02 rad一致性。失败不入图；重复几何仍可能导致错误回环，不能作为全局重定位保证。
回环边尺度(.02,.02,.01)，图求解失败撤销候选边，原始odom位姿始终不变。

新增输出：`/map/cloud`、重建 `/map`、`/path/graph_before`、`/path/graph_after`、`/slam/edges`及`/slam/status`。
前后图路径都在固定首帧选定的map基准中比较；before是原始里程计基线，不会被当前TF重复变换。
每次关键帧更新从原始扫描重新生成地图，不把校正点追加到旧地图；只积累关键帧，不是每个激光帧都入图。
SLAM独占map→odom，estimated适配器独占odom→base_link，模拟器只保留静态传感器外参。

RViz去掉rviz参数，可显示优化关键帧、紫色回环边、重建云和地图。当前主机GUI问题沿用第09章说明；
实际无界面ROS已验证24关键帧、1回环、地图/云/路径时间一致、唯一TF发布者、reset清空和局部odom不被图优化覆盖。

## 真实传感器矩形实验

使用14×12 m房间，内部圆与三角形，机器人半径.2 m；四段直线分别通过整段圆盘扫掠检查。
圆心沿6×4 m矩形每边6 s，以五次时间规律在拐角静止，机体yaw保持0（全向模型）。
360束、距离噪声.03 m，10 Hz激光与200 Hz IMU，seed=4242/6060；同一前端结果送给回环开启/关闭两图。
输出53关键帧，1个候选/1个接受回环（22.3 s）；27次激光拒绝、0次EKF拒绝。
位置RMSE只统计关键帧；末帧指标指最后关键帧22.8 s，并非24 s时刻，也不是首尾闭合距离。
回环并未让所有中间点的误差都下降。原始CSV/PGM/点云输出可复查，教材图表直接使用这些数据。

小规模实现每次关键帧都重建全部地图，便于读懂正确性，成本随关键帧增长；大场景应按子图增量更新。
本章无全局重定位、多机器人或动态场景剔除；长期失锁需要显式reset。两道练习和验收见exercises/ch10。
