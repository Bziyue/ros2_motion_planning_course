# 第 10 章：关键帧、回环与二维 SLAM

先修第08–09章与SE(2)。当前完成位姿图优化内核和独立合成实验；下一功能接入真实关键帧、
回环几何验证、地图重建与map→odom，不能把本页的合成约束当作已完成SLAM。

重新构建并加载ROS环境，在仓库根目录运行：

```bash
ros2 run motion2d pose_graph_demo tmp/ch10_graph
/usr/bin/python3 scripts/plot_ch10_graph.py
```

节点位姿Ti在map坐标，测量Zij把j坐标变到i坐标；误差是`Zij^-1 Ti^-1 Tj`的平移与归一化角度，
不是SE(2)对数映射。位置/航向使用加性更新，公开雅可比在`estimation/pose_graph.cpp`。
固定第0帧的三个量，使用Eigen稀疏LDLT和回溯线搜索。报告迭代上限、不可连通、奇异、求解失败和线搜索失败，
不把任何一次下降伪装为收敛。仅对回环的白化残差范数施加Huber，默认阈值3。

合成图为4×3 m矩形，80条相对边、81个节点；每步位置sigma=.01 m，航向sigma=.002 rad加固定.003 rad偏差，
seed=1010。边残差标准差(.03,.03,.02)，最后可加一条回到原点的独立约束，尺度(.02,.02,.01)。
第一帧始终固定原点。图中的参考位置仅评估RMSE，约束由实验生成器给出；这一步尚无地点识别或传感器配准。

核心验证：雅可比中心差分、非零首帧坐标、已知闭环恢复、一维加权解析解、错误回环鲁棒影响与断开图。
练习ch10-1推导并实现边残差；理解固定首帧与鲁棒损失局限。代码公开接口采用Doxygen。
