# 第15章：二维MINCO最小jerk

先修第14章。已完成最小jerk内核、解析伴随梯度与软约束/时间优化；ROS预览随后接入。

```bash
ros2 run motion2d minco_demo tmp/ch15_minco
/usr/bin/python3 scripts/plot_ch15_minco.py
```

Minco2D接收首尾TranslationState、N-1个内部位置、N个正时长，固定两端p/v/a。
每段五次、内部C⁴，按6N个条件组装上下带宽6的矩阵，一次求x/y系数；没有障碍或力约束。
jerkGram为解析积分矩阵，energyPartials给系数与固定系数时长偏导。
propagate解A^T*lambda=G，取路点行并扣除lambda:(dA/dT)C；完整时间梯度不能只取积分上限。
trajectory返回第14章通用曲线；内核无ROS依赖，ros2 run只是本机演示入口。

BandedLu无主元，针对本章方程顺序；不声称适用于任意矩阵。主元非有限/小于1e-14报数值失败。
秒/米单位和适中时长很重要，数学唯一性不等于任意浮点尺度稳定。

验收：1–6段与独立密集约束二次型一致（相对2e-9），C⁴误差<1e-8；
包含额外系数/时间代价的伴随中心差分通过（h=1e-5，相对2e-6）。
四段各1.5s、(0,0)→(1,1)→(2,-.2)→(3,.8)→(4,0)，首尾静止；
停靠/MINCO能量766.104/122.003m²/s⁵，采样速度峰值1.95256/1.47759m/s，加速度4.00819/2.77258m/s²。
同样路点不保证相同几何路线；低能量不能代替碰撞/动力学验证。
教材逐步解释最优性、带状解与伴随；练习ch15-1补全能量矩阵。

已补充 trajectory_optimization_demo：提供栅格上的位置/时长联合优化。
使用原始ESDF软距离、已膨胀走廊单位半空间、速度和加速度平方范数残差；梯形积分包括移动采样点的时间导数。
T=Tmin+exp(tau)，密集BFGS外层非线性优化，状态与采样可行性分别报告。
默认三组均收敛，但优化后穿出走廊（0.0166/0.0233m），联合优化净空下界0.1322m也不满足0.15m。
这是特意保留的真实结果；第16章连续凸包认证通过之前仅供预览，不作为执行命令。
