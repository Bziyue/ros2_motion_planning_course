# 第18章：线性MPC与约束跟踪

先修04/13/14/17。状态[px,py,vx,vy]，输入[Fx,Fy]；yaw仍用独立前馈PD。
精确ZOH复用ch04积分器的基响应，预测矩阵X=Sx*x0+Su*U。
代价为未来p/v误差、相对前馈的力、相对上一拍实际输入的力增量。
默认N20/h.02s、Qp40/Qv2/R.02/S.005；每轴2N、1m/s、5N/s，可选N个配置空间半空间约束。

```bash
ros2 run motion2d mpc_demo tmp/ch18_mpc
/usr/bin/python3 scripts/plot_ch18_mpc.py
```

box_qp.cpp是独立小型稠密ADMM正定QP，不是OSQP库。公开BoxQp方便检查真实P/q/A/l/u；绝对/相对残差默认1e-5。
失败区分max_iterations/time_limit/primal_infeasible/numerical_failure；坏维度或非正定P抛异常。
只有solved执行首输入；失败清除热启动，生成新的限幅阻尼力，不保证制动时的速度、变化率或避障。
成功原始序列左移一块，作为下一拍初值；不缓存失败的优化结果。

24s核心实验：50Hz、N10/20/40的RMS为4.63e-5/9.37e-6/5.56e-6m，QP组装+求解P95约.030/.083/.411ms，均无失败。
20Hz N20前瞻1s，与50Hz的.4s不同。模型精确、参考已知，无通信/估计噪声。
每轴.35N严格组：PD/MPC RMS .3533/.4771m；MPC21次未收敛，触发制动，最大变化率35N/s超出QP内2N/s。
这一失败记录保留在failures.csv。默认常规组完全可运行，严格组用于解释限制，不包装为成功导航。

测试包括无约束解析解、箱约束解、不可行证书、超时、A/B解析极限、展开代价梯度差分、约束行及实际反向制动。
另有短时域失去可行性反例：即使用最快允许减力，预测终点x=.30618m仍超过.3m边界；未实现终端安全集合。
走廊与速度约束仅在预测节点成立，不是连续无碰撞证明。ROS接入单独验收。
