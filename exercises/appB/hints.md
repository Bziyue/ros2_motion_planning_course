# 手算提示

- uL=v-b·omega/2，uR=v+b·omega/2。两式相加得v，相减得omega；再除轮半径得到角速度。
- 四组轮速：(4,4)、(-4,-4)、(-4,4)、(2,6)rad/s。
- 2/6圆弧v=.2、omega=.5、R=.4，t=π时位置(.4,.4)、yaw=π/2。交换后omega=-.5、R=-.4，位置(.4,-.4)、yaw=-π/2。
- 两轮同时加倍：圆半径不变，一圈时间由4π变为2π秒。
- 叉积dotp×ddotp=v²·omega；代入(.2,0)、(0,.1)得.02/.04=.5rad/s。
- 时间慢放s后v和omega均除以s，两轮速亦然；至少s=6/5=1.2，轮速变为5/3和5rad/s，曲率保持2.5m^-1。
- 原地逆时针旋转omega=1rad/s时v=0，左右轮为-4和4rad/s。位置曲线恒定，却能对应任意朝向，因此该点需要独立的旋转描述。
