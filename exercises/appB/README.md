# 附录B：从轮速到差速轨迹

1. 从无滑移弧长rw·Δφ推导轮接地点速度。再从左右轮相对中点的旋转位移推导v、omega及逆运动学。
2. **EXERCISE(appB-1)**：补全 `starter/wheels.hpp`。轮速输出顺序左、右，正角速度为逆时针。

```bash
mkdir -p tmp
c++ -std=c++17 -I exercises/appB/starter exercises/appB/check_wheels.cpp -o tmp/appB-check
./tmp/appB-check
```

直行、倒车、原地旋转、圆弧各25%，轮速绝对误差<1e-12；参考解在 `solutions`。

3. 取rw=.05m、b=.4m，手算(v,omega)=(.2,0)、(-.2,0)、(0,1)、(.2,.5)的轮速。
4. 从原点零朝向积分2/6rad/s轮速到t=π。交换轮速再算一次。运行 `differential_drive_demo`，对照圆心与四分之一圆终点。
5. 将两轮速都乘2：预测圆半径、一圈时间和朝向变化。实验时在自己的演示副本中修改指令，保留原数据作比较。
6. 用“旋转90°—前进—旋转回来”的动作解释为什么零侧向速度仍允许最终位置向侧面移动。
7. 从速度与加速度叉积推导omega。对p_dot=(.2,0)、p_ddot=(0,.1)手算轮速，说明朝向为何由运动方向决定。
8. 轮速上限5rad/s时，2/6rad/s圆弧应慢放几倍？推导速度、加速度、omega与轮速随时间缩放的比例。与阿克曼转角限制比较。
9. 为一段原地旋转写出v、omega和轮速；解释停点的位置输出为何不足以恢复朝向。画出含前进、停点与倒车的运动模式序列。
