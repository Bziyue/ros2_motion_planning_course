# 参考解

编译时将starter换成solutions。T=1的静止到静止多项式在t=.5时v=1.875，a=0；
同一几何路线T=2时v=.9375，a=0。一般第r阶导数按T^(-r)缩放。
原始系数c0=0,c1=c2=0,c3=10/T³,c4=-15/T⁴,c5=6/T⁵。
几何安全只由端点保证在线段内；非零连接导数的五次曲线需要额外验证。

ROS参考脚本check_ch14_time.py用独立6×6边界矩阵求系数；.203+.458=.661，.661+.637=1.298。
IMU在自身采样时刻取解析加速度，并旋转到yaw=.4的机体系；激光也用其自身时刻的位置和朝向。
实际206条IMU、11帧扫描通过，主机日志中的状态/IMU误差约7.3e-14，激光FLOAT32误差约4.8e-7m。
碰撞检测对每个tick的整段曲线使用加速度上界余量，先验证再推进时钟。
