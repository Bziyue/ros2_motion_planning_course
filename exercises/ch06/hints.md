# 第 06 章提示

ch06-1：R 将机体向量转到世界，反方向应用转置。水平运动的 a_z=0，g_z=-gravity，因此 f_z=+gravity。传感器在圆心，没有离心/切向的安装杆臂项；圆心本身沿圆运动时仍有向心加速度。

ch06-2：三轴协方差展开为九个数，对角索引是 0、4、8。sigma 的平方才是方差，不能平方两次。原始 IMU 的 orientation_covariance[0] 另有 -1 协议标记，与此练习的测量协方差不同。

ch06-3：先用较高精度计算 k/rate 秒，再乘 10^9 并舍入到整数纳秒。不要先舍入一个周期再乘 k。第一个 137 Hz 样本约在 7.29927 ms，需等 t=10 ms 的运动区间通过碰撞检查才能发布；它的 header 仍是 7.29927 ms。reset 不改变过去，它开始另一轮试验。

推导题参考：

- 10：非重力合力除以质量是 a−g，再用 Rᵀ 转回机体系。偏心安装增加 −ω²r=(−0.8,0) m/s²；角加速度再增加 αJr=(0,0.6) m/s²。
- 11：对角线为 4×10⁻⁶、9×10⁻⁶、16×10⁻⁶，其他元素为零。若 nₓ=.002Z、nᵧ=.003Z，则 E[nₓnᵧ]=.000006 E[Z²]=6×10⁻⁶，Cxy 和 Cyx 都非零。
- 12：第一步 v₁=n₀h、p₁=n₀h²/2；第二步 p₂=h²(3n₀/2+n₁/2)。独立同方差时 Var(p₂)=σ²h⁴(9/4+1/4)=2.5σ²h⁴。
- 13：N³=3Σj²+3Σj+N，而 Σj=N(N−1)/2。位置方差为 σ²(hT³/3−h³T/12)。N 较大时，固定 σ、频率翻倍，方差约减半，标准差约除以 √2；固定 q 则代入 σ²=q/h，方差近似 qT³/3，基本保持不变。
- 14：首两次为 7299270、14598540 ns，分别在 10、15 ms 派发。0.2 s 内有 28 个样本，去掉零时刻后为 27。第 1000 次直接计算为 7299270073 ns，周期舍入后累加为 7299270000 ns，相差 73 ns。
