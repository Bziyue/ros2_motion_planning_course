# 第 06 章提示

ch06-1：R 将机体向量转到世界，反方向应用转置。水平运动的 a_z=0，g_z=-gravity，因此 f_z=+gravity。传感器在圆心，没有离心/切向的安装杆臂项；圆心本身沿圆运动时仍有向心加速度。

ch06-2：三轴协方差展开为九个数，对角索引是 0、4、8。sigma 的平方才是方差，不能平方两次。原始 IMU 的 orientation_covariance[0] 另有 -1 协议标记，与此练习的测量协方差不同。

ch06-3：先用较高精度计算 k/rate 秒，再乘 10^9 并舍入到整数纳秒。不要先舍入一个周期再乘 k。第一个 137 Hz 样本约在 7.29927 ms，需等 t=10 ms 的运动区间通过碰撞检查才能发布；它的 header 仍是 7.29927 ms。reset 不改变过去，它开始另一轮试验。
