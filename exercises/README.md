# 习题组织

各章安排理解、代码和实验三类练习，按 `chNN/` 逐步创建。当前入口见 [ch01](ch01/README.md)。

```text
chNN/
  README.md       题目、先修知识、输入输出、验收标准
  starter/        少量 EXERCISE(chNN-N) 空缺的独立练习
  hints.md        分级提示
  solutions/      参考解与解释，教材默认不展开
```

演示算法保持完整可运行。练习通过独立编译目标或独立运行入口使用，不在默认演示路径中执行未完成的 TODO。

代码练习调用正式库中的稳定数据类型，只重写当章练习的短函数；不复制整套算法。评测既包含解析小例子，也包含一项可解释的实验指标。大纲中的数字均是初始参数建议，尚不是已验证的性能指标。
