## 分步手算

1. 对d=√(x²+y²)-1求偏导，在(0.6,0.8)求距离和梯度；沿x轴说明原点处为什么不可微。
2. 种子在(0,0)、(2,1)，查询(1,2)。先算第2行各列的竖直平方距离，再做横向最小化。ρ=.1 m时结果的单位是什么？
3. 令f=[0,4,0]，逐步填写sites与begin。推导两抛物线交点，说明为什么中心1会被删除；计算整数x=0,1,2处的最终值。
4. 取ρ=.2，四角值[0,.4,.6,1.04]，查询u=.3,v=.7。分别按两次线性插值、四权重展开计算值，并由链式法则求米制梯度。
5. 阻塞中心与自由中心相距ρ，距离样本分别为-ρ、+ρ。求插值零点与梯度，解释零点在墙面上时梯度为什么仍为2。
6. 从任意最近中心c*出发，用三角不等式推导|dc(p)-dc(q)|≤||p-q||。乘双线性权重求和，再减去障碍方格半对角线，得到clearance_lower_bound。
7. ρ=.2 m，四角距离[.6,.8,.6,.8] m，查询插值块中心。计算E、插值值和净空下界；与半径.2 m加裕量.05 m比较。若返回下界0，能否直接推断碰撞？
8. 220列点云中的格子(3,2)，计算点编号、点起始偏移和distance字段偏移；四个FLOAT32为何共16字节？
