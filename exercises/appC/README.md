扩展实验每次引入一种变化：

- 延迟/丢包：保留采集stamp，用到达时间队列；先固定80ms延迟，再研究乱序与缓存到期。
- 逐束畸变：根据各束真实采集位姿生成量程，使用估计轨迹去畸变；比较统一参考帧后的墙面误差。
- 凹多边形：在U形凹口选择自由点，依次检查点内、扫掠与射线查询。
- 动态障碍：画出机器人与障碍随时间的距离曲线，找出静态净空与未来碰撞不同的时刻。
- 全局重定位：设置远离旧位姿的复位，记录候选搜索、局部匹配与几何验证各阶段。

将独立偏置工具接到ROS IMU时，同步增加参数、每轴持久状态、reset及滤波过程噪声；先保持白噪声参数不变，以便分辨新模型的影响。
