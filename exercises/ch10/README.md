## 推导与手算

6. 固定 x0=0，顺序测量均为1 m，额外边测量为1.8 m。推导最小二乘的两个偏导、2×2正规方程和解。将额外边标准差减半，重新求解并比较各边残差。
7. 取 pi=(1,2)、yaw_i=90°，pj=(1,4)、yaw_j=90°，测量平移(2,0)、角度0。计算残差；将pj的全局x增加0.1 m，再算残差，解释它为什么出现在局部y分量。
8. 当Ri=Rz=I、q=(2,1)时，手写A和B。只增加起点航向0.01 rad，残差的一阶变化是多少？将这个结果与中心差分对照。
9. 残差(.06 m,0,.04 rad)，标准差(.03 m,.03 m,.02 rad)，计算白化残差、平方代价及阈值3的Huber权重。仅把x残差改成.12 m后重算权重。
10. 写出白化雅可比Ji,Jj对Hii,Hij,Hji,Hjj的四个贡献。若i=0被固定，哪些块和梯度仍会进入待求方程？解释全局数组偏移3(k-1)。
11. 推导正文错误回环例子的两种最优位置：普通平方损失5.5 m，Huber回环1.3 m。把回环阈值改成1后，最优位置是多少？检查解是否仍处在线性分支。
12. 正向变换为平移(1,0)、航向90°。求逆变换并验证复合为单位变换。再推导map→odom的旋转和平移公式，核对正文(11,-4)、90°的例子。
13. 同一全局刚体变换为何无法消除两帧点云之间已有的错位？从旋转保持长度推导，再用两次墙面观测各自的关键帧位姿解释重建步骤。
