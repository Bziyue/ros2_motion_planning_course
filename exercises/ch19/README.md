# 第19章：沿一条消息理解导航闭环

1. 用 p_x=2h(t/4)、h(s)=10s³-15s⁴+6s⁵，计算1.5 s的p/v/a。再使用未来交接提前量：当前1.2 s、交接1.5 s，说明应查询哪个时刻。比较取当前边界和取未来边界的差别。
2. **EXERCISE(ch19-1)**：补全 `starter/matching_boundary.hpp` 的位置、速度与加速度比较。构造位置相同但速度差0.1 m/s的候选，解释接收结果。
3. 调度实验：实际时刻1.2 s、候选起点1.5 s，依次查询1.6、1.2、1.4 s，再推进实际时刻到1.5 s。记录每次应选哪条参考，以及活动状态在哪一步改变。
4. 坐标手算：map=R*odom+b，R为90°旋转、b=(1,2)。map位置(1,3)、速度(0,0.5)对应什么odom状态？把b改成(1.1,2)，解释重新转换旧曲线会发生什么。对高次系数重复旋转往返。
5. 路线前缀：已走1.5 m、长度预算2 m、下一段为(0.6,0.8) m，算截断位移。改变原始未知格的边界，绘制原图与膨胀图，观察可达前沿候选位置。
6. 首速度对形状的影响：固定起点0、v0=0.5 m/s、a0=0、终点D=1 m且静止。从五次端点公式整理出 D*h(s)+v0*T*b(s)。计算T=2和8 s的中点，判断上界x<=1的走廊会怎样变化。
7. 接收实验：运行 `scripts/check_navigation_boundary.py`，按教材启动接收器。删去候选的一个区域，记录接收状态、确认及旧参考。解释一条消息为何要同时包含曲线、起点和区域。
8. **EXERCISE(ch19-2)**：补全 `starter/replan_due.hpp`。检查首次、暂停、到周期前1 ns、恰好到周期、等待交接与时间回退；列出最后一次尝试为1 s、周期0.2 s时的判断结果。
9. 数据年龄实验：使用 `scripts/check_navigation_failure.py` 的独立网格与时钟，保持里程计更新而中断扫描，再保持发送候选却不给确认。沿结构化状态追踪制动原因。
10. 误差手算：两次ATE位置误差为(0.01,0)、(0,0.02) m，求RMS。直线真值一秒走1 m、odom估计走1.02 m，求平移RPE。若某时刻里程计位置与参考相同，定位误差是否也为零？给出数值例子。
11. 固定种子运行A/B/C，记录初始对齐map ATE、odom一秒平移RPE、跟踪误差、真实圆盘净空、规划/MPC耗时和停车次数。比较A到B与B到C分别增加的因素。
12. **配置 ch19-3**：复制 `flat_vehicle.yaml`，启动两种模型×两种定位。说明truth目标(-6,-7.7)为什么对应SLAM的(2,0.3)。固定同一全向后端后再比较两种定位。
13. 每次只改一个量：vehicle.mass=3 kg、planning.force_max=0.5 N、planning.steering_max=0.005 rad。保存成功与未通过候选的状态、连续界、参考时长和跟踪误差，判断应改时间还是几何。
14. 比较物理上限、85%软目标与连续界上限；运动中发送 `/flat/stop`，观察轨迹撤销与新输入，使用第17章制动模型解释后续运动。
15. 由log-odds求两次自由证据后的概率，核对它与0.35自由阈值的关系。观察关键帧地图在何时增加第二次证据。
