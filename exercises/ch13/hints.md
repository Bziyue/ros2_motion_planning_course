# 提示

沿CCW多边形边前进，内部在左边；外法向指向右边。对水平向右的底边，外法向应向下。
先单位化法向，再用n.dot(a)计算b；否则半空间残差的单位不再是距离。
相邻凸集交集中任意一点都属于两个集；非退化凸多边形顶点的平均值位于其内部。

RViz按namespace/id保留标记；新消息变短不会自动删除未出现的旧id。路径头使用起点位姿时间，栅格头使用采样时间。


手算核对：矩形A的四行是(0,-1),(1,0),(0,1),(-1,0)，b=(-2,4,4,-1)。内部点残差(-1,-2,-1,-1)，外部点第二行为0.3。斜边法向(0.8,-0.6)，b=2。

线段证明逐行使用非负权重1-s、s；外推会出现负权重，不等号不能照搬。裁剪残差为-2、1，参数2/3，交点(2,5/3)；反向参数为1/3，世界交点相同。

交集[1,2]×[.5,1.5]的面积1 m²，平均(1.5,1)。对每个半平面，平均残差是各顶点残差的平均；正面积保证至少一个严格内点顶点，故平均为负。

种子为列2、3和行3、4，边界[.2,.4]×[.3,.5]；每侧最多2格。新加入一侧后，下一侧待查条带的长度会变化。L形示意中的(.5,1.4)位于凸包新增区。抛物线的中点为(.5,1)，两端在y=0；中间的高度由曲线形状决定。
