# 分级提示

1. 把线段写成 `a+t(b-a)`。
2. 点积投影的 t 可能小于 0 或大于 1，必须限制在闭区间。
3. a=b 时直接返回点到 a 的距离，不能除以零。

理解题：外形有半径；圆心到障碍物的距离必须大于半径。本课程将相切视为碰撞，安全裕量独立于物理半径配置。

## 手算核对

距离平方的导数为 `-2(p-a)·e+2t|e|²`。三点对应 t* 为 0.5、1.5、-0.5；截断后 t 为 0.5、1、0，距离为 1、√2、√2。最后一例的平方距离在 [0,1] 内递增。

凸包转弯叉积为 -2，表示右转；中间点在下边界上方，应从下链移除。内圆面积概率为 1/4。0.25 m 方格半对角线为 √2×0.125≈0.1768 m；边长减半后它也减半，世界格数约增至四倍（忽略边缘取整）。
