# 第18章：自己装配一个小 QP

1. 一步积分：从 m*v_dot=F-c*v 求零阶保持 A、B。取 m=2 kg、c=0、h=0.1 s，写出二维矩阵，并解释各块的单位。
2. 两步预测：使用教材单轴 m=1、c=0、h=1、N=2、初始静止的例子，写出 Sx、Su；输入(0.4,0.2) N时逐步核对位置与速度。
3. 代价展开：两个目标位置都是1 m，仅罚位置和力平方。手工展开 J 得到 P、q；消元求无约束最优输入，再加每轴0.4 N上限，求受限解与两个梯度分量。
4. **EXERCISE(ch18-1)**：补全 `starter/input_difference.hpp`。N=3，一轴输入(0.4,0.2,-0.1) N，上次实际输入0.1 N，核对 DU-d。若上一拍实际在制动，应该把什么放进 d？
5. 约束装配：继续两步例子，添加每步速度范围[-0.5,0.5] m/s、终点位置上界0.6 m，逐行写 C、l、u。再取上次实际力0.1 N、变化率0.2 N/s，添加输入增量行。
6. 数值迭代：一维 min(0.5*U²-2U)，-1<=U<=1，rho=sigma=1，从零开始。复算前三次，再算第4次的 U、z、y、原始和对偶残差。说明中间 U 超界时控制器为什么继续迭代。
7. 不可行证书：给 U>=2 和 U<=1 选择 v，检验 C^T*v 与边界加权和。与 max_iterations 的含义作比较。
8. 用两步例子的显式代价，在 U=(0.2,-0.1)处手算梯度；选一个小扰动对照中心差分。将这项计算与代码中的 PU+q对应起来。
9. 停车：复算教材 p=0、v=1、|F|<=1、h=0.1、N=1、位置上界0.15的例子。把初始速度降为0.5 m/s后，计算总停车距离。解释延长时域为何有助于更早发现运动无解。
10. 步内检查：p=t(1-t)，t从0到1，求最大位置及发生时刻，再与位置上界0.1 m比较。取哪些采样点会漏掉这个问题？
11. 固定八字参考和模型，比较 N=10/20/40、50/20 Hz，同时记录 Nh、位置RMS、最大误差、P95耗时和求解状态次数。把每轴力限收紧到0.35 N后，区分优化控制与制动时段。
12. ROS实验：从 `/control/mpc_status` 读取观测时间、残差与 compute_seconds。运行 `scripts/check_mpc_failure.py` 的独立时钟实验，核对预算耗尽时的新制动力方向。暂停仿真，观察预测时间戳是否保持。
