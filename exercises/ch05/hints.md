# 第 05 章提示

ch05-1：先判断判别式，再开方。两个根已经有大小顺序；先试小根，若为负再试大根，两者都负才是未命中。圆内起点恰好用于检查“不能只看小根”。

ch05-2：完整一圈有 N 个相邻角间隔，最后一个间隔跨越首末方向；部分视场的 N 个采样只隔开 N-1 段。NaN 的大小比较均为假，不能只写“若超出上下界则无效”的反向条件。

ch05-3：先用 isfinite 区分真正回波，再相加，最后检查量程。方差是标准差的平方；独立样本均值的标准差为 sigma/sqrt(M)。量程边缘丢弃部分样本后，保留的分布不再对称。

ch05-4：等腰三角形沿角平分线分成两个直角三角形，半弦长是 r*sin(Delta/2)。小角度可近似为 r*Delta，但检查包含大角度，不能只写近似式。小圆落在两束之间是角度采样漏检，和求交函数是否精确无关。
