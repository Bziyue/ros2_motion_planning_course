\section{重规划从未来交接时刻开始}
\begin{lstlisting}[language=bash]
ros2 run motion2d reference_handover_demo tmp/ch19_handover
/usr/bin/python3 scripts/plot_ch19_handover.py
\end{lstlisting}
假设当前仿真时间为 $t_0$，预留一段计算和传输时间后，在 $t_s>t_0$ 切换到新曲线。
新曲线不能从当前测量位置、零速度重新起步；应固定它的首边界为旧参考在 $t_s$ 的值：
\begin{equation}
 p_{\rm new}(0)=p_{\rm old}(t_s),\quad
 v_{\rm new}(0)=v_{\rm old}(t_s),\quad
 a_{\rm new}(0)=a_{\rm old}(t_s).
\end{equation}
这样交接前仍执行旧前缀，交接后才沿新路线走。实际机器人可能偏离参考，偏差由反馈处理；
若偏离已超出可接受范围，应制动和重新建立参考，而不是伪称仍有无缝接续。

\begin{figure}[!ht]
\centering\includegraphics[width=\linewidth]{figures/ch19_handover.pdf}
\caption{在 1.5 s 交接。旧曲线原本沿 x 轴到达 (2,0)，新曲线转向 (3,1)；
红点和竖虚线标记交接时刻。速度与加速度保持连续，jerk 不要求连续。}
\end{figure}

此时 p=(0.550415,0) m、v=(0.823975,0) m/s、a=(0.439453,0) m/s$^2$。
将新首速度简单置零，会立即产生与旧参考不匹配的速度跳变。
ReferenceSchedule 保存一条活动参考和至多一条未来候选；末端必须静止，才能连续接到终点保持。
这是参考调度实验，尚不以曲线平滑来声称已验证障碍或物理输入约束。

\section{预测未来，不等于提前切换}
MPC 会采样未来多个时刻。如果 sample 一查到未来就移动“当前曲线”指针，
下一次采样当前时刻时可能已经取错参考。
因此 sample 为只读函数，按查询时刻选择活动曲线或未来候选；
advance 只由真正推进的观测时刻调用。接口不保留过去所有曲线的历史，供当前与未来查询使用。
\lstinputlisting[language=C++,linerange={reference_handover_begin-reference_handover_end},includerangemarker=false]{../ros2_ws/src/motion2d/src/trajectory/reference_schedule.cpp}
过去的起点、尚未交接时积压的第二个候选，以及不连续边界都会被拒绝。
拒绝不能覆盖已有效的参考；reset 则显式清空活动与候选并设置新的静止锚点。
紧急重置会中断参考导数连续性，不能将它包装为普通 C$^2$ 重规划。

\section{地图校正与执行参考分开}
SLAM 回环可能改变 map 到 odom 的对齐关系。规划时冻结同一个变换，令
$p_m=Rp_o+t$；把地图中的曲线交给控制器前，使用
\begin{equation}
 p_o=R^T(p_m-t),\qquad v_o=R^Tv_m,\qquad a_o=R^Ta_m.
\end{equation}
对五次系数而言，每列都旋转，只有常数项平移；区域的所有顶点也使用同一变换，
再由顶点构建半空间。yaw 参考随坐标旋转一次，不从路径切向推断。
已发出的 odom 系数随后保持不变；新的地图校正影响下一次规划，而不直接跳动当前控制参考。

\paragraph{验证与练习}
测试包含交接前后 1 ns 的 p/v/a、提前预读未来、待交接状态、非法候选保留旧曲线、
终点保持与显式 reset。另将曲线和区域经平移 + 旋转送到 map 再变回 odom，验证所有导数和区域一致。
\begin{enumerate}
\item \textbf{ch19-1：}补齐 p/v/a 边界比较；同位置、不同速度或加速度必须拒绝。
\item 把新参考错误地连接到 $t_0$ 的状态，观察为何到 $t_s$ 时不能再匹配。
\item 分别说明定位误差、规划不满足约束、执行跟踪误差；平滑接续只解决其中的参考衔接。
\end{enumerate}

\section{只在观测自由空间里选择局部目标}
\begin{lstlisting}[language=bash]
ros2 run motion2d replanner_demo tmp/ch19_replanner
/usr/bin/python3 scripts/plot_ch19_replanner.py
\end{lstlisting}
规划输入是一份不可变快照：原始占据栅格、由它膨胀的配置空间栅格、同源未膨胀 ESDF。
目标在地图之外或明确占据时先报告错误；未知目标并不允许搜索穿越未知区域。
从未来交接点所在自由格做八邻接可达搜索，斜向仍禁止切角。
若全局目标已可达，就用 A* 找到它；否则，在可达自由格中选择靠近未知区、且更接近目标的一个格。

这些候选与原始未知格之间的搜索窗口由膨胀半径和分辨率确定。
它们是\textbf{局部探索候选}，不是承诺一定能发现通路的完整探索器。
失败状态分别说明当前局部搜索的结果：
\begin{itemize}
\item no\_progress\_frontier：候选的目标距离改善不足 0.1 m。
\item no\_reachable\_frontier：没有可达的未知边缘候选。
\end{itemize}
两者都不代表“整个未知世界一定无路”。
选好可达目标后，再沿 A* 路线弧长截取一段，默认最多 2 m；截断点仍位于已验证自由线段上。

\section{优化与备用方案都要通过认证}
对同一路线构建凸走廊，从第 19.1 节的未来 p/v/a 起步，终点设为静止。
Spline 优化同时使用 ESDF、走廊和速度/加速度软项；只有求解收敛且独立 Bézier 证书通过才接受。
本章核心默认开启控制点惩罚，走廊权重 50000、额外内缩 0.04 m；
软速度/加速度目标 0.45/0.5，证书上限 0.7 m/s 与 0.8 m/s$^2$。

若优化失败，不复用一个不合格的低代价值结果，而是尝试明确的备用方案：
各路点停下的五次段，\textbf{首段仍保留原来的 p/v/a}。
尝试基准时长与 1.5/2/3 倍时长，每次都重新检查同一组连续证书。
增加时长不一定能修复问题：固定非零首速度时，较长时间也可能把曲线推到走廊外。

\section{把轨迹与走廊作为一个事务接收}
\begin{lstlisting}[language=bash]
# Terminal 1: standalone receiver, no simulator
ros2 run motion2d tracker_node --ros-args \
  -p use_sim_time:=true -p reference.source:=navigation \
  -p control.odometry_timeout:=10.0
# Terminal 2: synthetic /clock and observations
python3 scripts/check_navigation_boundary.py
\end{lstlisting}
NavigationReference 把带绝对起点的五次系数、逐段凸区域、地图快照时刻放进\textbf{同一条消息}。
否则分别到达的“新曲线 + 旧走廊”可能组成一个从未被规划器验证过的组合。
区域顶点用 float64，避免 float32 舍入使贴边曲线的接收检查发生变化。
接收器检查消息坐标、区域数量、有限值及曲线在区域中的连续证书；
区域是否属于观测自由空间仍由规划器负责，控制器并不读取地图或世界。

\begin{center}\small
\begin{tabular}{ll}\toprule
话题 & 语义\\\midrule
/navigation/reference & 原子候选，坐标 odom\\
/control/accepted\_reference & Int64，已接收候选的起点纳秒\\
/navigation/stop & Empty，显式清空参考并制动\\
/control/reference & 当前观测时刻的参考位姿与机体速度\\
/control/reference\_acceleration & 同时刻的 odom 加速度\\\bottomrule
\end{tabular}
\end{center}
发布成功不等于控制器已经接受。规划端应等到对应起点的确认，再更新自己的参考调度；
每个待确认请求使用不同的未来起点，不能同时积压多个候选。
运动中的新曲线严格匹配旧参考的 p/v/a/yaw，拒绝候选时保留原曲线。
MPC 向前查询时，同时选择对应时刻的区域；第一条曲线尚未开始时，静止保持使用它的第一个区域。

\paragraph{启动与停车}
第一次启动，或显式制动后的重新启动，要求观测速度与角速度不超过 0.02，
首点在当前位置 0.03 m 内，yaw 差不超过 0.02 rad，并且首 v/a 为零。
这个小容差用于静止状态的测量波动，不能用于掩盖运动中的不连续交接。
制动会清空未来曲线、预测和显示路径，使用最新状态计算限幅阻尼力；
它不承诺制动过程仍满足旧曲线的连续证书或力变化率限制。

理想模式另设 control.controller=ideal，直接发送下一控制周期的参考位置，
仿真必须配套 ideal 模型并关闭 IMU；带质量模式仍发送力/力矩。
两者的物理含义不同，完整导航实验会分开报告。

\paragraph{验收与练习}
合成时钟测试先从静止沿 x 轴运动，再于 0.7 s 接续转向曲线。
检查确认只出现两次、交接前仍是旧曲线、交接处 p/v/a 相等、错误替换不覆盖有效参考，
以及显式停车发布新的阻尼力、移动中拒绝重新锚定。
练习：故意去掉第二条消息的一块区域，再重复发送；说明为什么既不能确认，也不能丢掉原参考。

\paragraph{明确的失败处理}
扫描超过 0.35 s、里程计超过 0.12 s 或地图超过 3 s 未更新，都会清空参考并制动。

等待静止后可重试仍保留的目标；这不是完备探索，也不保证总能恢复或到达。
用结构化状态区分规划失败、等待静止、等待确认、执行和到达，另记录优化器状态、耗时、停车次数。

初始未知格约占 88.9\%--92.9\%，到达时仍有约 74.7\%--76.4\% 未知；
导航只探索本次任务需要的区域，并没有读入完整世界地图。
详细数值保存于 textbook/data/ch19\_navigation.csv，脚本另输出逐时刻定位、跟踪、状态和 QP 数据。
异步回调到达次序与有限墙钟预算会影响具体重规划时刻；相同种子保证几何和噪声流，
不保证操作系统调度或最终路径逐位相同。

\paragraph{怎样解释成功率}
9/9 是三个固定种子、同一起终点、短距离静态场景的本次结果，样本太少，
不能推断任意未知环境都有这样的成功率。
长窄通道、不可见凹陷、低激光重叠和动态障碍可能导致停滞；
当前前沿选择只追求更靠近目标，不具备完整的全局探索策略。
这些单程任务也没有主动制造回环；实际回环实验见第 10 章，
本章另用曲线/区域坐标往返和新旧参考测试验证地图校正不会直接重写已发出的 odom 曲线。

\paragraph{验收与继续练习}
检查节点订阅表：导航、控制、激光里程计、EKF 和 SLAM 都不能订阅 ground\_truth 或 sim 位姿。
分别增大噪声、减小激光量程、降低重规划频率，记录\textbf{失败状态和停车次数}，不要只保留成功曲线。
当前主机完成无界面 ROS 实验，RViz 的预期内容已配置；桌面图形问题尚未解除，未声称截图验收通过。

\section{从观测就绪到未来起步}
启动时暂停；在另一个已加载环境的终端恢复，然后给出当前可达的近目标：
\begin{lstlisting}[language=bash,numbers=none]
ros2 service call /sim/pause std_srvs/srv/SetBool '{data: false}'
# truth mode: start (-8,-8), goal (-6,-7.7), yaw=0
ros2 topic pub --once /goal_pose geometry_msgs/msg/PoseStamped \
  '{header: {frame_id: map}, pose: {
     position: {x: -6.0, y: -7.7}, orientation: {w: 1.0}}}'
ros2 topic echo /flat/status
\end{lstlisting}
SLAM 第一帧作为初始 map 原点，同一相对目标改为 $(2,0.3)$。
当前配置要求初始 yaw=0，保持估计 odom 和全向施力轴一致。
目标必须携带有效平面四元数；阿克曼采用其中的终点朝向，全向仍保持起步朝向。

SLAM 的第一帧自由概率 0.4 尚未低于规划的 0.35 阈值，
\code{waiting_observed_free_start} 会等下一份观测地图。
后续关键帧增加证据才继续，不为尽快开车降低自由判据。
A* 和凸走廊都来自同一份膨胀地图；固定路径曲率不适合小车时，专用优化器可明确失败。

\textbf{求解完成不等于现在开始。}仅在观测速度、角速度以及阿克曼转角接近零时求解，
预算默认 1 s。成功后还要等求解结束之后的一条新里程计，
以其 stamp 加 0.3 s 设执行起点；避免使用计算期间排队的旧观测。
路径和区域由同一 map 到 odom 变换冻结，后续定位校正不重写已发出的系数。
新地图若使区域失效，则清空参考并制动。

\begin{lstlisting}[language=bash,numbers=none]
ros2 topic pub --once /flat/stop std_msgs/msg/Empty '{}'
ros2 service call /sim/reset std_srvs/srv/Trigger '{}'
\end{lstlisting}
暂停保持同一个模拟时间，不重复推进控制；reset、非法目标和显式停车清空旧参考。
有新鲜里程计但激光/地图/转角过期时，以新状态给限幅阻尼输入；
里程计也超过 120 ms 时，改为零输入，避免反复使用旧速度制动而使车辆反向加速。
这是明确的故障处理，不是原轨迹连续证书的一部分。

\textbf{接口与显示。}阿克曼曲线通过 \code{/flat/ackermann_trajectory} 输出，
几何参数 $u$ 无量纲，每段另存物理秒和绝对起点；空曲线表示撤销。
\code{/flat/reference} 是当前观测时刻的 Odometry 参考。
RViz配置显示观测地图、注册点云、选定里程计、\code{/plan/path} 和凸区域；
完整世界与仿真圆盘属于可选真值对照。此主机完成无界面验证，未声称新增GUI画面已验收。

\paragraph{ch19-3 配置练习}
先逐项改变质量、规划力上限、转角上限，每次只改变一个量，记录状态、认证界、时长与跟踪误差。
解释物理上限、参考软目标和后验认证之间的关系，失败样本也写入报告。
