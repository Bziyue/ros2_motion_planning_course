\section{静止的加速度计为什么不为零}
把一个加速度计平放在桌上，它的 z 轴向上时会测到约 $+9.81\ \mathrm{m/s^2}$。
这不是机器人正在加速上升，而是桌面的支持力产生了比力。自由落体才接近零比力；
本课程机器人受平面约束，不模拟自由落体。

设 $R$ 将机体系向量转到世界系，$a$ 是圆心的世界运动加速度，$g$ 是世界重力：
\begin{equation}
f=R^\top(a-g),\qquad g=(0,0,-g_0)^\top,\qquad g_0=9.81\ \mathrm{m/s^2}.
\end{equation}
后续估计器若要恢复运动加速度，需要 $a=Rf+g$，并且必须使用自己的姿态估计。
仿真器内部可用真值 yaw 生成测量，估计器不能把它当作 IMU 给出的姿态。

\begin{center}
\begin{tikzpicture}[>=Stealth]
\draw[thick,navy] (-2,0)--(2,0) node[right] {水平支撑面};
\draw[fill=tealblue!15,draw=tealblue,thick] (-.6,0) rectangle (.6,.45);
\draw[->,thick,tealblue] (0,.45)--(0,1.65) node[above] {$f_z=+g_0$};
\draw[->,thick,navy] (1.1,.3)--(1.1,-1) node[below] {$g_z=-g_0$};
\node[left] at (-.6,.25) {圆盘中心};
\end{tikzpicture}
\end{center}

本章 IMU 在圆心，与 \code{base_link} 同向。机器人只做水平平移和 yaw 转动，
因此 $a_z=0$、roll=pitch=0。陀螺仪理想输出 $(0,0,\dot\psi)$，单位 rad/s，
加速度计理想输出的单位是 $\mathrm{m/s^2}$，不是 g 的倍数。
这一约定参考 \href{https://github.com/ros-infrastructure/rep/blob/master/rep-0145.rst}{REP-145 的 IMU 报告约定（草案）}。

\section{用三行公式读懂理想 IMU}
二维部分只需要一个旋转转置：
\begin{equation}
\begin{bmatrix}f_x\\f_y\end{bmatrix}
=\begin{bmatrix}\cos\psi&\sin\psi\\-\sin\psi&\cos\psi\end{bmatrix}
\begin{bmatrix}a_x\\a_y\end{bmatrix},
\qquad f_z=g_0,\quad \omega_z=\dot\psi .
\end{equation}
例如 yaw 为 $90^\circ$、世界加速度为 $(2,0)$ 时，
世界的 +x 方向正好是机体的 -y，故 $f=(0,-2,9.81)$。

\lstinputlisting[language=C++,linerange={imu_ideal_begin-imu_ideal_end},
  includerangemarker=false]{../ros2_ws/src/motion2d/src/sim/imu.cpp}

\code{ImuSample} 只保存角速度与比力两个三维向量，算法不依赖 ROS。
输入的 \code{acceleration} 成员由动力学或解析轨迹提供；
不要用含噪位置二阶差分代替它。

\textbf{运动模型的选择。}第四章的 \code{reference} 提供一致的解析位置、速度和加速度；
\code{inertial} 从力、质量和阻力计算加速度。二者适合本章。
\code{ideal} 瞬移没有物理导数，\code{velocity} 的速度突变需要脉冲加速度，
都不能据此伪造可融合的 IMU。

\textbf{安装位置的意义。}圆心原地自转时，圆心不产生向心加速度。
圆心本身沿圆轨迹移动时则有。若以后把 IMU 安装到偏离圆心的位置，
需要加入角速度和角加速度引起的杆臂项；本章不暗中模拟这些项。

\begin{notebox}
加速度计不能区分静止和匀速直线运动；两者的运动加速度都是零。
原始 IMU 也不直接测量位置、速度或绝对 yaw。
\end{notebox}

\section{让每个采样点带上一点白噪声}
最小测量模型将理想值与独立的高斯误差相加：
\begin{equation}
\omega_m=\omega+b_g+n_g,\qquad f_m=f+b_a+n_a,\qquad b_g=b_a=0.
\end{equation}
每个轴的每次采样独立，$n_i\sim\mathcal N(0,\sigma_i^2)$。
本章先不模拟偏置、温漂或随机游走，也不把噪声裁剪到几个标准差内。
同一采样的六个误差各抽一次；不能为整段运动只抽一个常数误差。

\lstinputlisting[language=C++,linerange={imu_noise_begin-imu_noise_end},
  includerangemarker=false]{../ros2_ws/src/motion2d/src/sim/imu.cpp}

默认陀螺仪三轴标准差为 $(.002,.003,.004)$ rad/s，加速度计为
$(.04,.05,.06)\ \mathrm{m/s^2}$。这些是\textbf{每采样标准差}，不同轴可以不同。
世界、雷达、IMU 各自拥有随机引擎；改变雷达束数不会推进 IMU 随机流。
\code{reset} 重新设置 IMU 种子 6060，没有跨帧保留的高斯分布缓存。
同配置、同轨迹、同采样顺序和同一标准库下可逐值重放，不承诺跨标准库字节一致。

\begin{notebox}
\textbf{标准差不等于噪声密度。}必须先说明频谱约定、滤波带宽与采样方式才能换算。
若连续白噪声强度为 q，且每个读数是长度 $\Delta t$ 的独立区间均值，
则 $\operatorname{Var}(n_k)=q/\Delta t$。这只是一个明确假设下的关系；
本章直接配置每采样 $\sigma$，改频率时不会自动改变它。
\end{notebox}

\section{原始消息不提供航向答案}
话题 \code{/imu/data_raw} 使用 \code{sensor_msgs/Imu}，帧为 \code{imu_link}。
\code{linear_acceleration} 字段装比力，不能仅凭字段名认为它已经去重力。
姿态四元数用单位值占位，协方差首项 -1 明确表示没有姿态估计。
这遵循主机定义及\href{https://github.com/ros2/common_interfaces/blob/rolling/sensor_msgs/msg/Imu.msg}{官方 Imu 消息约定}。

独立噪声使 $C=\operatorname{diag}(\sigma_x^2,\sigma_y^2,\sigma_z^2)$；

\section{用统计量验收噪声}
先在 ros2\_ws 运行独立实验：
\begin{lstlisting}[language=bash,numbers=none]
ros2 run motion2d imu_noise_demo
ros2 run motion2d imu_noise_demo \
  > ../textbook/data/ch06_noise.csv
\end{lstlisting}
使用 seed=6060、每轴 $N=60000$ 个误差样本。均值和总体标准差分别为
\begin{equation}
\bar n=\frac1N\sum_k n_k,\qquad
s=\sqrt{\frac1N\sum_k(n_k-\bar n)^2}.
\end{equation}
下面直接读取演示生成的 CSV；g 行单位为 rad/s，a 行为 $\mathrm{m/s^2}$。
\begin{center}

  columns/mean/.style={column name=实测均值,fixed,fixed zerofill,precision=6},

零均值指分布的期望，不要求有限样本均值恰好为零。均值的标准误为 $\sigma/\sqrt N$，
因此测试使用 $|\bar n|<5\sigma/\sqrt N$，标准差相对误差小于 2\%。
单元测试还检查六轴间和相邻时刻的相关量，防止不小心复用随机误差。

\textbf{真实 ROS 消息实验。}启动默认第 06 章场景后运行 \code{check_ch06.py}。
它收集 200 Hz、$t=0$ 到 10 s 的 2001 条圆参考消息。先减掉理想值
$(0,0,.4)$ 和 $(0,.16,9.81)$，再检验残差；不要对包含运动的原始值直接求“噪声均值”。
因样本较少，标准差容差为 8\%，均值仍用五个标准误。
脚本也检查无缺帧、协方差、QoS、暂停和 41 帧 reset 重放；缺帧会明确失败。

\section{零均值误差也会积成漂移}
暂时假设姿态已知且固定，只研究一个水平加速度轴和 yaw 角速度的噪声。
这排除了姿态误差与重力耦合，便于手算，不是惯性定位算法。
把每个噪声样本看作一个时长 $h$ 内的常值：
\begin{equation}
\delta\psi_{k+1}=\delta\psi_k+n_{g,k}h,\quad
\delta p_{k+1}=\delta p_k+\delta v_k h+\tfrac12 n_{a,k}h^2,\quad
\delta v_{k+1}=\delta v_k+n_{a,k}h.
\end{equation}
独立噪声的方差相加。经历 $N$ 个区间后，
\begin{align}
\operatorname{Var}(\delta\psi_N)&=\sigma_g^2Nh^2,\\
\operatorname{Var}(\delta p_N)&=\sigma_a^2h^4
 \sum_{j=0}^{N-1}(j+\tfrac12)^2
 =\sigma_a^2h^4\frac{N(4N^2-1)}{12}.
\end{align}
当 $T=Nh$ 固定且 N 较大，位置方差近似 $\sigma_a^2hT^3/3$。
固定每采样 sigma 与固定连续白噪声强度，是两个不同的频率对比实验。

\lstinputlisting[language=C++,linerange={drift_integration_begin-drift_integration_end},
  includerangemarker=false]{../ros2_ws/src/motion2d/src/examples/imu_noise_demo.cpp}

\begin{lstlisting}[language=bash,numbers=none]
ros2 run motion2d imu_noise_demo --drift
\end{lstlisting}
实验固定 $h=.005$ s、$T=10$ s、1000 次试验、seed=6060。两组复用同一随机序列，
只把 sigma 倍率从 1 改为 2。表中为位置误差 RMS 与解析标准差，单位 m：

统计上的 RMS 增长不意味着单次误差的绝对值每步都增大。

\section{在 RViz 中同时观察激光与 IMU}
从 ros2\_ws 构建、加载 install 后运行，默认选择连续的圆参考：
\begin{lstlisting}[language=bash,numbers=none]
ros2 launch motion2d_bringup ch06.launch.py
# Another terminal, same ROS environment
/usr/bin/python3 ../scripts/check_ch06.py
\end{lstlisting}
参数在 \path{motion2d_bringup/config/ch06.yaml}，改后重启。
\code{imu.rate} 默认 200 Hz，\code{imu.noise_seed} 为 6060；
\code{imu.gyro_stddev}、\code{imu.accel_stddev} 均为长度 3 的数组。
当前比力依赖连续运动，因此启用 IMU 时只接受 reference 或 inertial。
要做静止实验，可选 inertial 且不发力；不可切换到瞬移模型生成伪 IMU。

\textbf{常见问题：}只收到激光而无 IMU，先检查本章配置及模型；
暂停后新订阅者收不到旧 IMU 属于 Volatile QoS 行为，恢复运行再观察。
检查程序会 reset 并最终暂停。重置会让时间回退，已有 TF 缓存需要进入新试验；
必要时恢复运行或重新启动 RViz，不把旧缓存警告当作新运动数据。
