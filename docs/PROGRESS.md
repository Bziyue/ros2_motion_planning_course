## 第 02 章：时钟与 TF

- 整数 tick 的时间内核，暂停、仅暂停时单步、归零后暂停。
- 唯一 /clock，3 条静态 TF 和 1 条动态 TF；传感器显式圆心外参。
- 3 个时钟单元测试；实际通信脚本检查解析 yaw、暂停冻结、单步恰好 5 ms、reset 与恢复。
- 图中的两米向量为坐标演示，不冒充尚未实现的激光扫描。
- reset 后真实 TF Buffer 能重新查询 map 到 laser；RViz2 已截图确认恢复正常。静态外参以 1 Hz 墙钟重发，避免时间回退清空监听缓存后丢失静态边。
- 本机 TF 显示插件经过时间回退后退出出现崩溃，默认改用两个 Axes 显示坐标轴后，重置与正常退出均通过；完整 TF 通信不受影响。
