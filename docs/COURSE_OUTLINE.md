## 1. 课程目标与学习路线

目标读者会基本 C++、向量和微积分即可开始；矩阵、概率、最小二乘、优化的必要知识在用到前补充。先运行、看见现象，再解释数学，再改一小段代码。

课程最终形成三条可切换的实验路线：

| 路线 | 位姿与执行 | 地图来源 | 主要目的 |
| --- | --- | --- | --- |
| A：规划入门 | 真值里程计 + 理想位置/轨迹执行 | 激光 + 真值位姿构建的观测地图 | 单独理解路径、避障和轨迹 |
| B：控制入门 | 真值里程计 + 带质量模型 + PD/MPC | 同上 | 单独理解惯性、约束和跟踪 |
| C：综合导航 | 激光/IMU SLAM + 带质量模型 + MPC | SLAM 地图 | 研究估计误差、重规划和闭环效果 |

环境生成器掌握完整障碍物，只服务仿真和评估。额外提供显式 `oracle_map` 对照实验，不能把读取完整世界当作激光建图。真值路线也默认只使用已经观测到的地图。

推荐顺序为 01-20。若想先看规划，可以学完 01-07 后用路线 A 跳到 11-16，再回到 08-10；先修关系会在每章开头标明。

## 2. 建模与控制量建议

**推荐主线：二维全向圆盘。** 状态描述圆心位置与速度，圆盘半径负责碰撞。偏航角用于雷达/IMU 坐标转换，平移与偏航先解耦。它是便于教学的平面机器人模型，也可作为无人机水平运动的简化；不宣称具有四旋翼的完整姿态与推力动力学。

| 模型 | 输入 | 优点 | 教学限制 |
| --- | --- | --- | --- |
| 理想位置执行 | 下一位置/位姿，或有时间参数的参考轨迹 | 最快看到规划效果；支持用户指定到点 | 离散跳变不产生物理有效的 IMU；不能穿过障碍 |
| 全向运动学 | 平面速度与偏航角速度 | 容易理解积分、坐标变换 | 不解释质量与执行器限制 |
| 全向惯性（推荐进阶） | 世界系平面力 `Fx,Fy` 与偏航力矩 `tau_z` | 质量确实影响运动；适合线性 MPC | 没有车轮非完整约束，也没有飞行器姿态耦合 |
| 差速机器人（附录） | `v,omega`，再扩展到左右轮速/轮力矩 | 更接近扫地机器人 | 不能横向移动；需要曲率、朝向及非完整约束 |

惯性主线：`p_dot = v`，`m v_dot = F - c_v v`，`yaw_dot = omega`，`I_z omega_dot = tau_z - c_omega omega`。质量、阻尼、转动惯量和输入上限均有单位与参数。均匀圆盘默认 `I_z = m r²/2`，允许单独指定；几何质点 `r=0` 时不使用零惯量做偏航动力学。

上层可以输出期望加速度，再由明确的控制分配得到力。不能直接用加速度更新速度后声称验证了质量效应。差速模型若被选为主线，第 14-18 章必须同步调整可行轨迹和控制器，不能仅更换一个输入名字。

## 3. 章节和代码如何对应

计划只用三个 ROS 包：算法与薄节点 `motion2d`、启动配置 `motion2d_bringup`、必要自定义消息 `motion2d_interfaces`。算法按目录分层，不按章节复制。

以下 `sim/foo.cpp` 等算法路径均相对于 `ros2_ws/src/motion2d/src/`，相应声明位于 `include/motion2d/`。每章共同有：

- `textbook/chapters/chNN.tex`：正文与真实代码摘录。
- `chapters/chNN/README.md`：先修知识、命令、参数、预期现象。
- `motion2d_bringup/launch/chNN.launch.py`、`config/chNN.yaml`、`rviz/chNN.rviz`：只在该章需要时创建。
- `exercises/chNN/`：题目、starter、分级提示、参考解。
- 与该章关键算法相邻的有意义测试，以及可重复的实验脚本。

每章完成标准：编译运行 → RViz2 对照图 → 一个解析/数值检查 → 一个改参数实验 → 习题与答案解释 → PDF 排版检查。大纲阶段不会预先生成这些空壳。

## 第一篇：从主机环境到可观测的二维仿真

### 第 01 章：主机环境、ROS 2 与第一个 RViz2 场景

- **目标**：理解工作空间、package、node、topic、launch，显示固定网格和一个圆盘。
- **内容**：本机 Lyrical 检查；干净环境的安装路线；colcon；source 顺序；rclcpp 发布 Marker；RViz2 Fixed Frame；统一仿真时间的预告。
- **已实现代码**：`nodes/hello_scene_node.cpp`；最小 `CMakeLists.txt` / `package.xml`；`ch01.launch.py`。
- **练习**：解释 topic 类型与节点的区别；补完一个圆形 Marker；改变半径、颜色、坐标，记录显示变化。
- **验收**：从新终端按教材命令构建并启动；RViz2 显示圆盘，命令行能查看消息；还没有机器人运动或 SLAM。

### 第 02 章：二维几何、坐标、时间与接口

- **目标**：能够把雷达点从机体系变换到世界系，读懂时间戳和 TF 树。
- **内容/公式**：`p_world = R(yaw) p_body + t`；角度归一化；SI；`map → odom → base_link`；`laser` 与 `imu_link` 静态外参；仿真时钟、频率与简单 QoS。
- **已实现代码**：`geometry/se2.cpp`；`sim/sim_clock.cpp`；`nodes/frame_demo_node.cpp`；`ch02.launch.py`。
- **练习**：手算旋转 90 度的点；实现变换的逆；比较错误时间戳与正确时间戳的显示。
- **验收**：正反变换恢复原点；TF 每个子帧只有一个父帧；暂停时 `/clock` 与仿真状态同时停止。

### 第 03 章：随机圆形与多边形障碍物世界

- **目标**：构建可复现、可配置、可验证的简单静态环境。
- **内容/公式**：边界矩形、随机圆、通过随机点凸包生成的凸多边形；点在线段/多边形内；点到边界距离；圆盘碰撞；种子、起终点净空与可达性检查。凹多边形分解为选做。
- **已实现代码**：`geometry/obstacles.cpp`；`sim/world.cpp`；`sim/world_generator.cpp`；`nodes/world_scene_node.cpp`；`ch03.launch.py`。
- **练习**：理解“碰撞半径”和图形尺寸；补完点到线段距离；固定种子改变障碍密度，解释不可达场景。
- **验收**：同一参数与种子重复生成同一世界；圆和多边形均显示；无效多边形不进入世界；失败场景报告原因，不静默换种子。

### 第 04 章：圆盘机器人、理想质点与受力惯性

- **目标**：区分几何外形、运动学和动力学；先手动移动，再观察加速与制动。
- **内容/公式**：位置、速度、yaw、角速度；理想到点与连续理想轨迹；速度积分；`m v_dot = F - c_v v`；时间离散；力/力矩限幅；碰撞事件与试验停止。
- **已实现代码**：声明 `include/motion2d/sim/robot_model.hpp`；`sim/ideal_model.cpp`、`sim/velocity_model.cpp`、`sim/inertial_model.cpp`、`sim/reference_model.cpp`、`sim/swept_collision.cpp`；`nodes/simulator_node.cpp`。本章连续参考为解析圆，任意分段多项式参考在第 14 章接入。
- **练习**：预测相同力下两种质量的加速度；补完一步积分；比较时间步长与制动距离。
- **验收**：零力与恒力实验符合解析结果；改变半径影响碰撞；理想位置跳转检查扫过的圆盘，不允许跨过障碍。真正 reset/瞬移明确开始新试验并清理缓存，不用于 IMU 实验。

### 第 05 章：均匀角度扫描激光雷达的 CPU 实现

- **目标**：从一束射线推导一整圈扫描，认识测距误差和离散分辨率。
- **内容/公式**：雷达位于圆心；射线与线段/圆的最近交点；`alpha_i = alpha_0 + i Delta_alpha`；360 度扫描不重复首末方向；量程、束数、频率、可选高斯测距噪声。
- **已实现代码**：`sim/raycast.cpp`；`sim/lidar_cpu.cpp`（几何扫描与可选噪声分开）；`ros/lidar_messages.cpp`；`ch05.launch.py`；`examples/lidar_noise_demo.cpp` 与 `examples/lidar_benchmark.cpp`。
- **练习**：推导射线与圆二次方程；补完最近正交点选择；用 90/360/720 束比较边界和 CPU 耗时。
- **验收**：简单墙面和圆的距离与解析值一致；无回波为 `+inf`；RViz2 同时显示光束和命中点。小于近距盲区的真实命中定义为无效读数 `NaN`，建图跳过；不能冒充远距离空闲。

### 第 06 章：带高斯白噪声的 IMU 与传感器时间

- **目标**：理解 IMU 测量的是角速度与比力，不是位置，也不是直接可用的真值姿态。
- **内容/公式**：`omega_m = omega + b_g + n_g`；`f_m = R^T(a-g) + b_a + n_a`；每采样独立高斯噪声、协方差、种子；偏置先为零，随机游走为选做。默认水平面 `g=(0,0,-9.81)`，静止原始 IMU 的 z 比力约为 `+9.81 m/s²`。
- **计划代码**：`sim/imu.cpp`；`sim/sensor_scheduler.cpp`；噪声统计脚本。
- **练习**：推导机体转动后的加速度分量；补完方差到消息协方差的映射；比较噪声标准差与积分漂移。
- **验收**：静止、恒速、已知加速度与旋转运动符合预期；均值/方差在统计容差内；未提供姿态时 `orientation_covariance[0] = -1`。非连续位置跳转不发布伪造 IMU。

### 第 07 章：真值里程计、激光点云与占据栅格

- **目标**：先把建图和定位分离，完成可用的规划输入基线。
- **内容/公式**：真值 `Odometry`；扫描转 `PointCloud2`；光线清空与终点占据；log-odds 更新；unknown/free/occupied；地图分辨率；真值、odom、map 的对齐。
- **计划代码**：`mapping/scan_projection.cpp`；`mapping/occupancy_grid.cpp`；`nodes/truth_odometry_node.cpp`；`nodes/mapping_node.cpp`。
- **练习**：解释无回波与未知区域的区别；补完栅格光线遍历；比较地图分辨率、雷达噪声和障碍厚度。
- **验收**：只利用激光与真值位姿生成点云、地图；遮挡后的空间仍未知；`+inf` 清空量程内光线但不生成障碍端点；与独立真值栅格比较已观测区域误差。

## 第二篇：由里程计走向激光/IMU SLAM

### 第 09 章：IMU 预测与激光校正的二维融合

- **计划代码**：`estimation/imu_predictor.cpp`；`estimation/planar_ekf.cpp`；`estimation/scan_deskew.cpp`。
- **练习**：手推一个状态转移雅可比；补完 yaw 角残差归一化；比较纯激光与融合在快速旋转、扫描丢失时的表现。
- **验收**：输出连续 `/odometry/estimated`；IMU 高频传播、激光低频校正；固定轨迹对比位置/角度误差。说明局部地图与估计共享历史带来的相关性，教学 EKF 不宣称严格统计一致或达到工业 LIO 水平。

### 第 10 章：关键帧、回环与完整二维 SLAM

- **内容/公式**：关键帧与子图、排除近期帧的回环候选、几何验证、SE(2) 位姿图、固定首帧消除自由度；`min sum e_ij^T Omega_ij e_ij`；回环后重建地图；`map → odom` 校正与连续 odom 的区别。
- **计划代码**：`estimation/keyframes.cpp`；`estimation/loop_closure.cpp`；`estimation/pose_graph.cpp`；`nodes/slam_node.cpp`。
- **练习**：解释位姿图为什么需固定一个参考；补完一条图边的残差；沿矩形闭环运行，比较开/关回环的漂移。
- **验收**：显示回环边、优化前后轨迹和重建点云/栅格；检查误回环；SLAM 只订阅模拟激光、IMU 及固定外参。教学范围为静态、小尺度二维场景，长期地图管理和失效后全局重定位另作进阶。

## 第三篇：从路径到连续轨迹优化

- **计划代码**：`planning/inflation.cpp`；`planning/astar.cpp`；`planning/path_simplifier.cpp`。

### 第 12 章：二维 ESDF、插值与梯度

- **内容/公式**：占据栅格到欧氏距离变换；有符号距离（自由为正、占据为负）、双线性插值、梯度；`d(p) >= r + margin`；障碍格中心距离与障碍单元边界距离的差别。
- **计划代码**：`mapping/distance_transform.cpp`；`mapping/esdf.cpp`；距离场可视化。
- **练习**：画出圆障碍的解析距离场；补完插值/梯度；改变分辨率，对比精度与计算时间。
- **验收**：解析小场景比较距离与梯度；明确未知格处理与离散误差的保守余量；未膨胀 ESDF 加一次半径，或膨胀配置空间场对零阈值，不能双重膨胀。

### 第 13 章：二维凸安全走廊

- **内容/公式**：沿 A* 路径扩张保守矩形，再推广为凸多边形；半空间 `A_i p <= b_i`；相邻走廊交叠、路点分配、窄通道与失败处理；配置空间中的整块验证。
- **计划代码**：`planning/corridor.cpp`；`geometry/halfspace.cpp`；走廊 Marker。
- **练习**：解释凸性为何有用；补完半空间包含判断；比较矩形与多边形走廊的覆盖范围。
- **验收**：走廊内部及边界不与膨胀障碍/未知格相交，相邻分段有可用交叠。只检查顶点或随机采样不能作为走廊无碰撞证明。

### 第 14 章：从折线到五次多项式轨迹

- **内容/公式**：路径与带时间轨迹的区别；`p_i(t)=sum(k=0..5) c_ik t^k`；端点位置/速度/加速度；分段连续性、采样、时间分配；平移轨迹与独立 yaw 参考。
- **计划代码**：`trajectory/polynomial.cpp`；`trajectory/quintic.cpp`；`trajectory/sampler.cpp`。
- **练习**：求一个一维起终点静止的五次多项式；补完一阶/二阶导数；改变时长，比较速度和加速度峰值。
- **验收**：端点和连接处的约束达到数值容差；保存时长与系数，绘制 p/v/a；理想连续轨迹执行能精确复现参考。仅连通路点尚不意味着整条曲线避障。

### 第 15 章：二维 MINCO 最小 jerk 轨迹

- **内容/公式**：`J = integral ||p'''(t)||² dt`；给定路点与正时长的最小控制能量解；消去多项式系数；带状求解；路点/时间梯度；正时长参数化；时间代价、ESDF/走廊和动力学惩罚；约束验证。
- **计划代码**：`trajectory/minco2d.cpp`；`trajectory/trajectory_cost.cpp`；`trajectory/time_allocation.cpp`。
- **练习**：推导单段 jerk 能量矩阵；补完一个局部梯度；比较固定时长与时间优化的轨迹、能量和最小净空。
- **验收**：小问题与密集约束二次型参考解一致；解析梯度通过有限差分；输出优化状态与约束残差。罚函数小不代表已满足安全约束。

### 第 16 章：SplineTrajectory 的二维教学实现与对照

- **内容**：在相同 clamped 最小 jerk 问题上，解释块三对角求解、解析能量梯度、伴随传播与模块化代价；写固定二维五次核心；读取固定版本上游作数值对照；Bezier 凸包与走廊约束。
- **计划代码**：`trajectory/spline2d.cpp`；`trajectory/spline_optimizer2d.cpp`；`trajectory/bezier_bounds.cpp`；独立上游对照示例。
- **边界**：不完整复刻任意维、全部阶数、MINVO 基底与所有优化器接口；不是把通用库包一层就代替教学实现。上游初始参考 SHA 见 `REFERENCES.md`。
- **练习**：解释“同一曲线的不同表示”；补完二维块消元或一项伴随梯度；固定问题比较 MINCO、本地 Spline2D 与 `QuinticSplineND<2>` 的误差和耗时。
- **验收**：端点、连续性、能量、梯度达到事先约定的数值容差；控制点全部位于已验证凸走廊可用于整段包含性检查；软惩罚后另做可行性验证。性能结论以本机实测为准。

## 第四篇：轨迹跟踪与闭环导航

### 第 17 章：先用前馈 + PD 跟踪带质量模型

- **先修**：04、14；可先于 15-16 试验。
- **内容/公式**：位置误差、速度误差、前馈加速度；`F = m(a_ref + Kp e_p + Kd e_v) + c_v v`；输入饱和；独立 yaw 控制；跟踪误差与碰撞裕量。
- **计划代码**：`control/pd_tracker.cpp`；`control/command_adapter.cpp`；误差绘图脚本。
- **练习**：解释只用位置反馈的滞后；补完输入限幅；比较圆形/八字参考、质量误差和阻尼的影响。
- **验收**：同一轨迹对比理想执行与动态执行；报告 RMS/最大误差、输入峰值、最小净空；参数变化有可解释的效果。

### 第 18 章：线性 MPC 与约束轨迹跟踪

- **内容/公式**：状态 `[px,py,vx,vy]`，输入 `[Fx,Fy]`；离散质量/阻尼模型 `x_(k+1)=A x_k+B u_k`；有限时域误差/控制增量代价；力、速度、输入变化与凸走廊约束；QP、滚动优化、热启动；yaw 暂用独立控制器。
- **计划代码**：`control/linear_mpc.cpp`；`control/qp_problem.cpp`；OSQP 或同类小型求解器适配。
- **练习**：推导一步 A/B 矩阵；补完代价或一个约束块；比较 PD/MPC、预测时域、控制频率和求解时间。
- **验收**：简单无约束情况与解析结果相符；约束有效、状态明确；超时/不可行时停止使用旧优化结果，执行已定义的限幅制动。ESDF 非线性约束不伪装为原来的线性 QP；单列为选做 SQP/NMPC。

### 第 19 章：接通 SLAM、在线重规划与完整实验

- **内容**：路线 A/B/C 配置切换；地图快照、局部目标、分段探索未知区域；ESDF/走廊更新；重规划频率与控制频率分离；新旧轨迹 p/v/a 衔接；回环时坐标变换；规划失败、传感器中断与制动策略。
- **计划代码**：`nodes/navigation_node.cpp`；`planning/replanner.cpp`；少量明确状态；批量实验脚本。
- **练习**：解释定位误差、规划误差和跟踪误差的区别；补完重规划触发；在相同种子下比较 A/B/C 三条路线。
- **验收**：静态未知环境中持续更新地图并到达目标，或明确报告当前不可达；回环校正不造成控制参考跳变；成功率、碰撞次数、ATE/RPE、跟踪误差、最小净空和求解延迟均可复现。真值仅参与评估。

## 第五篇：性能与进一步扩展

### 第 20 章：CUDA 激光雷达仿真加速（选学）

- **先修**：05 和 C++ 数组/内存；先读 CPU 基准结果再优化。
- **内容**：逐束并行、几何数据布局、设备内存复用、归约求最近命中、线程/块、主机设备传输；CPU/CUDA 后端使用相同场景和扫描接口。
- **计划代码**：`sim/lidar_cuda.cu`；`sim/lidar_backend.cpp`；独立 benchmark；可选 CMake 开关。
- **练习**：估算束数与障碍数的工作量；补完一个 ray-circle 内核；比较不同束数/障碍数下的内核耗时与端到端耗时。
- **验收**：首先关噪声逐束对比 CPU/CUDA 的命中和距离；再对相同真值距离应用相同噪声样本；报告预热、同步、传输和消息发布成本，小场景 GPU 更慢也如实报告。无 CUDA 时全部主线仍可构建运行。

### 附录（按需选学）

- **A 数学补充**：SE(2)、矩阵与最小二乘、概率/协方差、雅可比、凸集、QP、数值差分。
- **B 差速扫地机器人**：`x_dot=v cos(yaw)`，`y_dot=v sin(yaw)`，`yaw_dot=omega`；轮距/轮半径、非完整约束、曲率与低速问题、轨迹适配和 NMPC。主线不默认依赖此模型。
- **C 进阶感知/仿真**：IMU 偏置随机游走、延迟/丢包、凹多边形、逐束扫描畸变、动态障碍、全局重定位；均不混入基础章节。
- **D 接入外部工具**：rosbag2 回放、与现有二维 SLAM 做对照、Doxygen 文档、实验报告模板。

## 5. 教材风格、代码风格与验收

每章采用“本章能看到什么 → 一个小实验 → 图示 → 必要公式 → 对应函数 → 参数实验 → 习题 → 小结”的顺序。首次出现的字母解释单位；推导放侧栏/附录；正文不堆论文式记号。书中区分路径、轨迹、控制、定位和建图。

使用 XeLaTeX + ctex，中文正文、统一色板、清晰层级、可点击目录、带编号公式和图表。算法示意用 TikZ，实验结果来自实际日志，关键代码从真实源文件引用；完整教材不截取过长源码。

C++ 使用普通值类型、Eigen 和薄节点，关键接口及公式采用 Doxygen。每章练习给明确输入/输出和验收标准。核心测试优先解析例子、数值差分和固定种子实验；不为了覆盖率堆砌与实现完全同构的测试。

验收指标在每章实施前写出定义、场景与容差。里程计用对齐规则明确的 ATE/RPE，地图误差只在已观测区域统计，规划/控制统计成功率、净空、输入、延迟与失败状态。SLAM 全局自由度通过首帧或评估对齐处理，绝不把评估真值回灌算法。
